# Security

Do not include secrets in issues, pull requests, support notes, examples, or screenshots.

Secrets include passwords, API keys, OAuth tokens, private keys, customer private data, raw transcripts, billing details, bank details, tax IDs, and credentials.

For security-sensitive reports or setup help, use the `get-help` skill to prepare a redacted support note, then contact What If It Works through the official website:

https://whatifitworks.co

This template is local-first. Review `.codex/config.toml`, `.claude/settings.json`, `.agents/schedules.yaml`, `.agents/recurring.yaml`, and any MCP or API configuration before enabling hooks, background jobs, or external tools.
