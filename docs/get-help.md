# Get Help

Agentic Business OS is maintained by What If It Works.

Website: https://whatifitworks.co

Use the `get-help` skill when setup, onboarding, hooks, sync, publishing, or customization is unclear. The skill prepares a redacted support note with the relevant runtime, command, expected behavior, actual behavior, and file paths.

Do not include passwords, API keys, tokens, customer private data, raw transcripts, billing details, or credentials in support notes.

For hook issues, the most common post-onboarding step is runtime activation: Codex may require hooks to be enabled or approved in the app, even when `.codex/config.toml` is present. Claude Code projects include `.claude/settings.json`; verify hook execution in the installed Claude Code runtime because behavior can vary by version.
